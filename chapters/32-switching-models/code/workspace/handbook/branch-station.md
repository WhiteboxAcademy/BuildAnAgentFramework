# Station branch

Address: Unit 3, Central Station concourse.
Branch manager: Mei Tanaka.

Opening hours: Every day 06:00 to 20:00.

Equipment service contractor: Northline Service, 0300 555 0177.

Station has no seating and sells takeaway only. Staff need a concourse pass from the station office, which Mei arranges in your first week. The goods lift is closed between 08:00 and 09:30.
