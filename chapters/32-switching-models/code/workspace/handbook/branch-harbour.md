# Harbour branch

Address: 4 Quay Walk.
Branch manager: Lena Ortiz.

Opening hours: Monday to Friday 06:30 to 16:00. Saturday and Sunday 07:30 to 15:00.

Equipment service contractor: Tidewater Espresso Service, 0300 555 0142.

Harbour serves the morning ferry crowd, so the first hour is the busiest of the day. It has outdoor seating for 16, which must be brought in if the wind warning flag is up on the quay.
