# Riverside branch

Address: 22 Mill Race Road.
Branch manager: Sam Achebe.

Opening hours: Monday to Saturday 07:30 to 18:00. Sunday 09:00 to 16:00.

Equipment service contractor: Northline Service, 0300 555 0177.

Riverside is the only branch with a kitchen, so it is the only branch that makes hot food. It also hosts the Thursday evening cupping club, which runs from 18:30 to 20:00.
