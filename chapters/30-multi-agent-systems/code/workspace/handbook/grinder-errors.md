# Grinder error codes

The Mazurka M4 grinders show a code on the front panel.

- E12: hopper empty. Refill it, then press the dial.
- E27: burr chamber blocked. Switch it off, unplug it, and clear it with the blue brush.
- E31: motor overheating. Leave it switched off for 20 minutes.
- E44: dose sensor fault. Use the backup grinder, and report the fault.
- E58: internal board fault. Don't restart it. Report it as a repair.

If the same code comes back three times in one day, treat it as a repair.
