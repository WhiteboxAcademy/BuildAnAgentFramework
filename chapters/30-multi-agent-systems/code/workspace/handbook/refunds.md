# Refunds

If a customer is unhappy with a drink, offer to remake it first. Remakes need no approval.

Refunds under £10 can be given by any barista. Refunds of £10 or more need a shift lead. Card refunds go back to the original card and can take up to 5 working days to arrive. Retail beans can be refunded within 30 days if unopened, and with a receipt.

Record every refund with reason code R2 for a quality problem, R3 for a wrong order and R5 for a price error.
