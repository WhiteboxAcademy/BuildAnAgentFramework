# Allergens

We handle milk, soya, nuts, gluten, egg and sesame on site. Because of this we can never promise that a product is free from an allergen.

If a customer mentions an allergy, stop and check the allergen folder, even if you think you know the answer. Change your gloves, and use clean utensils and a clean steam jug.

The almond croissant and the seeded flapjack are the highest-risk products. Never guess. If the label is missing, the item must not be sold.
